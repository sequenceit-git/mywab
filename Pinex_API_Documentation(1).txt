Send an HTTP POST with a JSON body and Content-Type: application/json.

1. Request Fields

key required Your generated API key. No request is allowed without a valid key.
type required uc = return UniPin vouchers. topup = redeem vouchers to a player id. shell =
redeem a shell item to a player id.
product required UC: 20,36,80,160,161,405,800,810,1625,2000. Shell:
lite,lvl6,lvl10,lvl15,lvl20,lvl25,lvl30.
quantity required How many pieces, e.g. 3.
orderid required Any value. Echoed back as-is. Duplicates are allowed.
playerid topup/shell Required when type = topup or shell. Not needed for uc.
url required Your callback URL. The result JSON is POSTed here.

6. Notes

• All amounts are in BDT.
• Balance is charged first; if it is not enough, the remainder goes to your due within the baki limit.
• Every request is processed under a per-user lock, so balance never goes below zero and the baki limit is never
exceeded.
• orderid is informational only and is echoed back; concurrent requests with the same orderid stay isolated.
• On any failure (uc or topup) vouchers are never exposed and are returned to stock; any charge is refunded.
• Shell items use no voucher pool; they are redeemed directly to the player id. On failure any charge is refunded (partial
failures get a partial refund).
• Shell (like uc and topup) works for both USD and BDT accounts and is fully counted in your due.
• Callback timeout: if the external server does not send its confirmation callback in time, the request is treated as
delivered — the charge is kept and is NOT refunded. For uc/topup the voucher is still shown so it can be redeemed
manually (no player nickname); for shell the result is marked 'timeout'. Only real failures (insufficient credit / wrong
player id / region doesn't match / server down) are refunded.
• API request fee: each topup and shell piece charges a small extra fee (default 0.15) on top of the product price,
deducted from your balance or due limit. uc is never charged. If you cannot afford BOTH the product price and the fee,
the order is blocked for balance. If the service request limit is temporarily exhausted, the order fails with content
'api request limit over'. On a FULL refund the fee is refunded too; on a PARTIAL completion the fee is not refunded.
• Activity messages for every request are also delivered to your Telegram inbox.
